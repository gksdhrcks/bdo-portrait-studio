# 검은사막 초상화 스튜디오 1.3

클래스별 기본 그림과 외부 참조 그림으로 AI 초상화를 만들고, 글자·구도를 편집해 624×804 BMP로 저장하는 데스크톱 프로그램입니다.

## 앱 안에서 업데이트하기

**옵션 → 업데이트 확인 → 업데이트 확인 → 업데이트 적용 및 재시작**을 사용합니다.

GitHub Releases에서 현재 운영체제용 배포 ZIP과 검증 정보를 받습니다. 새 버전이 없으면 최신 버전이라고 표시합니다. 저장소는 기본으로 `gksdhrcks/bdo-portrait-studio`를 사용합니다.

업데이트를 적용하기 전에 현재 편집 상태와 자료함을 저장하고, `StudioData/updates/`에 자료함 전체와 기존 프로그램 파일을 백업합니다. 다운로드 크기·SHA-256·압축 파일 경로를 검사한 뒤 별도 설치 프로세스가 앱 종료를 기다려 프로그램 파일을 교체하고 재시작합니다. 적용 오류가 발생하면 교체한 프로그램 파일을 복원합니다. 기본 그림·결과·폰트가 있는 `StudioData`는 설치 대상에서 제외됩니다. API 키는 실행 중 메모리에만 보관하므로 재시작 후 다시 입력합니다.

업데이트에는 쓰기 가능한 프로그램 폴더와 인터넷 연결이 필요합니다. 공개 GitHub Release가 배포된 뒤 사용할 수 있으며, 저장소가 없거나 배포가 아직 없을 때는 오류를 알립니다. GitHub 로그인이나 사용자 토큰은 앱에 저장하지 않습니다. 처음 v1.3을 적용한 뒤부터 앱 메뉴로 업데이트할 수 있습니다.

개발자는 버전을 올리고 GitHub에 소스를 반영한 다음 **Actions → Publish application update → Run workflow**를 실행하거나 `v버전` 태그를 올립니다. Windows/macOS/Linux 빌드·검사가 성공하면 실행 파일, 공통 소스, `update.json`이 Release에 올라갑니다. 개인 자료함과 API 키는 배포 대상에서 제외합니다.

## 클래스·보스 기본 그림 등록

**초상화 종류**에서 **클래스** 또는 **보스·몬스터**를 선택합니다. **그림 한 장 추가**로 파일 한 장만 등록하거나 기존처럼 폴더를 추가할 수 있습니다. 인식하지 못한 이름은 종류·이름·전투계열을 직접 지정합니다.

- 보스 목록: 가모스, 벨, 크자카, 누베르, 카란다, 쿠툼, 귄트, 무라카, 미루목 파괴자 오핀, 산군, 금돼지왕, 우투리, 불가살, 흑봉황. 다른 몬스터는 이름을 직접 등록할 수 있습니다.
- `가모스.png`, `garmoth.jpg`는 보스·몬스터 / 가모스 / 기본으로 자동 연결합니다. 보스 그림 유형은 기본이며, 글자 레이어의 표시 문구는 자유롭게 바꿉니다.
- 오공·스칼라·데드아이·세라핌·아처: 개방 / 기본. 샤이: 재능 / 기본. 에이전트: 전승 / 기본. 일반 클래스: 각성 / 전승 / 기본.
- `오공.png`, `스칼라.png`처럼 전투계열이 없는 파일은 개방으로 연결합니다. `샤이.png`는 재능으로 연결합니다. 일반 클래스는 파일명에 전투계열이 없으면 직접 지정해야 합니다.
- `오공_각성.png` 같은 불일치는 **전투계열 확인 필요**로 표시합니다. 파일 연결 확인에서 개방으로 적용하세요. 기존 보관 결과는 삭제하지 않습니다.
- 보스 생성 요청문은 종족·체형·뿔·날개 등 고유 외형을 유지하도록 준비합니다. 기본 이미지와 참조 이미지는 직접 등록합니다.

## 생성 방식 선택

화면 위 **생성 방식**에서 세 경로를 선택합니다. 처음 실행하면 ChatGPT 웹이 선택되며, 이전 사용자는 마지막 선택을 유지합니다.

| 방식 | 생성 위치 | 비용·준비 |
|---|---|---|
| ChatGPT 웹 | 브라우저에서 사용자가 생성 → 프로그램으로 결과 가져오기 | API 키 없이 웹 구독의 이미지 생성 한도 사용 |
| OpenAI API | 프로그램에서 생성·자동 보관 | 별도 API 결제 설정과 API 키 필요 |
| ComfyUI | 연결된 로컬/원격 ComfyUI에서 생성 | 사용자의 모델·워크플로 필요. 원격 서비스 비용은 해당 서비스 기준 |

### 먼저 ChatGPT 웹으로 사용해 보기

1. 기본 그림 폴더를 추가하고 클래스·전투계열을 지정합니다. 참조 그림, 젠더, 유지할 특징, 추가 요청을 선택합니다.
2. 상단에서 **ChatGPT 웹**, 가운데 **ChatGPT 웹 작업 열기**를 누릅니다.
3. **① 현재 선택으로 새 작업 준비**를 누릅니다. 첫 웹 작업은 기본 그림이 있으면 자동 준비됩니다. 창에 준비된 기본 그림·참조 그림의 썸네일과 결과 연결 대상이 표시됩니다.
4. **요청문 복사**, **첨부 그림 폴더 열기**, **ChatGPT 열기**를 차례로 누릅니다.
5. ChatGPT 웹에서 직접 로그인하고, 폴더의 `01_base.png`와 `02_reference.png`(있을 때)를 채팅창에 첨부합니다. 요청문을 붙여 넣고 그림 생성을 요청합니다.
6. 완성된 그림을 다운로드합니다. 웹 작업 창의 **결과 가져오기 영역** 또는 메인 미리보기 위에 다운로드한 **그림 파일 한 장**을 끌어 놓습니다. **결과 그림 파일 선택**으로도 가져올 수 있습니다. 채팅 화면의 그림 대신 다운로드한 실제 파일을 사용하세요.
7. 결과가 자료함에 자동 보관되고 메인 화면에 표시됩니다. 글자·구도를 조절한 뒤 BMP·PNG·프로젝트로 저장합니다.

웹 작업은 준비 당시의 클래스·전투계열·글자·폰트·참조 설정을 보관합니다. 다른 클래스를 보고 있어도 가져온 결과는 선택한 웹 작업의 클래스에 연결됩니다. 작업 창 위의 목록에서 이전 작업도 다시 선택할 수 있습니다. 다른 클래스나 요청으로 만들 때는 **현재 선택으로 새 작업 준비**를 누르세요. 결과의 확대·이동은 새 그림 전체가 보이도록 초기화하고, 글자·하단 명암 설정은 유지합니다.

이 창은 요청문과 파일 전달을 돕습니다. 로그인·첨부·생성·다운로드는 웹에서 직접 진행하며, 웹을 열거나 작업을 준비하는 것만으로 AI 요청이 전송되지 않습니다. 실제 웹 모델은 자동 확인할 수 없어 선택 입력한 이름을 **사용자 입력·미검증**으로 기록합니다. 환경이 파일 끌어 놓기를 지원하지 않으면 파일 선택 버튼을 사용하세요.

진행 중인 웹 작업과 첨부 원본도 `.bdostudio` 백업에 포함되며, 새 위치에서 첨부 폴더를 다시 만듭니다. 웹 계정의 로그인 정보는 프로그램에 저장하지 않습니다.

공식 이미지 생성 안내: https://learn.chatgpt.com/docs/image-generation

### v1.1에서 업데이트

프로그램을 종료한 뒤 기존 `StudioData` 폴더를 유지하고 실행 파일과 안내 파일을 새 버전으로 교체합니다. 또는 새 배포 폴더에서 자료함 백업을 가져옵니다. 배포 ZIP에는 사용자 자료함이 포함되지 않습니다.

## 기본 그림과 결과를 프로그램에 보관하기

v1.1부터 그림의 경로만 기억하는 방식 대신 **그림 파일 자체를 내부 자료함에 복사**합니다. 처음 기본 그림을 등록하고 클래스를 지정하면 원본 폴더를 옮기거나 삭제해도 다시 사용할 수 있습니다.

- AI 생성 결과는 자동 보관됩니다. **보관된 결과**에서 다시 열고 편집할 수 있습니다.
- AI 생성 없이 기본 그림을 편집한 경우에는 **현재 편집본을 자료함에 보관**을 누릅니다.
- 클래스별 글자·구도, 참조 그림과 사용 폰트, ComfyUI 워크플로 설정도 함께 보관합니다.
- 편집한 결과와 현재 작업 상태는 앱을 닫았다 다시 열어도 유지됩니다.

기본 배포본에는 `portable.txt`가 들어 있습니다. 쓰기 가능한 프로그램 폴더에서 실행하면 다음 구조로 저장됩니다.

```text
프로그램 폴더/
  BDOPortraitStudio.exe       # Windows 예시
  portable.txt
  StudioData/
    PortraitLibrary.bdostudio # 기본 그림·결과·폰트·편집 설정이 담긴 실제 자료함
    cache/                    # 자료함에서 다시 만들 수 있는 임시 표시 파일
```

**다른 컴퓨터로 옮기는 방법**은 두 가지입니다.

1. 앱을 종료한 뒤 `StudioData`가 포함된 프로그램 폴더를 통째로 복사합니다. 같은 OS에서는 바로 실행하면 됩니다.
2. **자료함 → 자료함 백업 내보내기**로 `.bdostudio` 파일 하나를 저장합니다. 새 컴퓨터에서 해당 OS용 프로그램을 실행하고 **자료함 → 자료함 백업 가져오기**로 선택합니다. 기존 자료함은 자동 백업한 뒤 가져온 자료함으로 전환합니다.

Mac·Linux·Windows 사이에서도 자료함 형식은 같습니다. 실행 프로그램은 각각 해당 OS용을 사용해야 합니다. 폴더가 읽기 전용이면 사용자 데이터 폴더에 저장하므로, **자료함 → 자료함 폴더 열기**에서 실제 위치를 확인하거나 백업 메뉴를 사용하세요. **실행 파일 하나만 복사하면 자료함은 따라가지 않습니다.**

API 키와 워크플로의 인증 정보는 자료함에 포함하지 않습니다. 새 컴퓨터에서 AI 연결은 다시 확인해야 하며 ComfyUI의 모델·커스텀 노드는 별도로 준비해야 합니다. 이 기능은 로컬 보관과 파일 이동 방식이며, 클라우드 계정의 자동 동기화 기능은 포함하지 않습니다.

이전 v1.0 설정이 있고 원본 기본 그림 폴더를 아직 찾을 수 있으면 첫 실행 때 내부 자료함으로 복사합니다. 이전에 외부 폴더로 저장했던 결과는 **파일 → 프로젝트 열기**로 한 번 열면 자료함에도 보관됩니다.

## 실행

### Windows

Windows 배포본의 `BDOPortraitStudio.exe`는 Python 설치 없이 실행합니다.
소스 배포본은 Python 3.10 이상을 설치한 뒤 `start.bat`를 실행합니다.

### macOS

Python 3.10 이상(Tk 포함)이 필요합니다. 소스 폴더에서 터미널로:

```sh
bash start.sh
```

또는 실행 권한을 준 `start.command`를 엽니다. python.org 배포 Python에는 Tk가 포함됩니다.

### Linux

Python 3.10 이상과 Tk, venv가 필요합니다. Ubuntu/Debian 예:

```sh
sudo apt install python3 python3-venv python3-tk
bash start.sh
```

처음에는 가상환경을 만들고 Pillow와 tkinterdnd2를 내려받습니다. 이후에는 AI 연결을 사용하지 않는 한 네트워크 없이 편집·저장할 수 있습니다.
그래픽 데스크톱 세션이 필요합니다. 게임 자체의 OS 지원 범위와는 별개입니다.

## 사용 순서

1. **기본 그림 폴더 선택**. 하위 폴더의 PNG/JPG/WebP/BMP를 확인하고 내부 자료함에 복사합니다.
2. **파일 연결 확인**. 인식 실패·중복·손상 파일이 있으면 목록을 엽니다. 클래스를 직접 입력하거나 선택하고 전투계열을 지정한 뒤 **선택한 파일에 적용**을 누릅니다. 중복 그림은 사용할 한 장을 남기고 나머지를 사용 제외합니다. 원본 파일 이름은 바꾸지 않습니다.
3. 메인 화면에서 **클래스와 전투계열**을 고르면 연결된 기본 그림이 표시됩니다.
4. **외부 참조 그림**을 가져오면 썸네일과 이름이 표시됩니다. 참고할 요소, 젠더, 유지할 특징, 추가 요청을 선택합니다.
5. **OpenAI API·ComfyUI**는 **AI 연결 설정 → 연결 확인 → AI로 초상화 생성**. **ChatGPT 웹**은 위의 웹 사용 순서를 따릅니다. 생성하거나 가져온 결과는 내부 자료함에 자동 보관됩니다.
6. 생성 후 **AI 결과** 화면에서 글자를 드래그하거나 레이어별 폰트·색·크기·위치·외곽선을 조절합니다. 화살표는 1%, Shift+화살표는 0.25% 이동합니다. 확대와 구도는 즉시 바뀌며, 외형이나 젠더 변경은 다시 생성해야 합니다.
7. 저장 폴더 선택 후 **BMP · PNG · 프로젝트 저장**. 새 하위 폴더를 만들어 기존 작업을 덮어쓰지 않습니다.

저장되는 파일:

- `source.png`: 글자와 자르기 처리를 하기 전 고해상도 그림
- `portrait.bmp`: **624×804, RGB 24비트 BMP**
- `portrait.png`: 최종 초상화 PNG
- `project.json`: 레이어·구도·생성 서비스/요청 모델·참조 경로 등 재편집 정보

파일 메뉴의 **프로젝트 열기**로 `project.json`을 열면 원본과 편집 상태를 복원합니다. 템플릿은 글자와 구도만 별도로 저장합니다. 다른 OS에서 열 때 없는 폰트는 해당 컴퓨터의 폰트로 바뀌므로, 최종 결과를 확인하고 원하는 TTF/OTF/TTC를 선택하세요.

## 파일 이름 자동 연결

예:

```text
기본그림/
  다크나이트_각성.png
  무사_전승.bmp
  위치/
    각성/portrait.png
  dark_knight/awakening/portrait.png
```

확실히 인식할 수 있는 이름만 연결합니다. 전투계열이 없거나 여러 클래스가 겹치면 자동 추측하지 않습니다. 이름이 다른 그림도 직접 지정하면 되고, 연결 정보는 프로그램 설정에 기억합니다. 새 클래스는 직접 입력해 추가할 수 있습니다. 각성·전승 외에 기본·재능·개방도 지정할 수 있습니다. 실제로 보유한 그림을 기준으로 연결하세요.

## OpenAI API

**AI 연결 설정 → OpenAI API**에서 API 키와 이미지 모델명을 입력합니다.

- 기본 요청 모델: `gpt-image-2.5-sunburst` (계정에서 이용할 수 있는 다른 GPT Image 모델명을 직접 입력 가능)
- API 키는 메모리에서만 보관하며 설정·프로젝트 파일에 쓰지 않습니다. `OPENAI_API_KEY` 환경변수도 지원합니다.
- 연결 확인은 해당 모델 접근을 검사합니다. 실제 이미지 생성 권한과 API 잔액까지 보장하는 검사는 아니며, 요청 실패 시 서버 오류를 표시합니다.
- ChatGPT 구독과 별개인 OpenAI API 사용 요금이 적용됩니다.
- 기본 그림을 첫 번째 입력, 외부 참조를 두 번째 입력으로 이미지 편집 API에 보냅니다. 생성된 이미지에는 글자를 넣지 않고 앱에서 글자를 합성합니다.
- API에 명시한 요청 모델명과 서버가 별도로 보고한 모델명을 구분해 생성 기록에 저장합니다. API가 실제 모델명을 반환하지 않으면 요청 모델명만 기록합니다.

공식 문서: https://developers.openai.com/api/docs/guides/image-generation

## ComfyUI

ComfyUI를 따로 실행하고 **AI 연결 설정 → ComfyUI**를 엽니다.

1. 서버 주소를 입력합니다. 기본값은 `http://127.0.0.1:8188`입니다.
2. ComfyUI에서 **API 형식**으로 내보낸 워크플로 JSON을 불러옵니다. 일반 화면 저장 JSON(`nodes` 배열)은 사용할 수 없습니다.
3. 기본 그림을 받을 이미지 입력(예: `LoadImage.image`), 참조 그림을 받을 별도 이미지 입력, 프롬프트 입력(예: `CLIPTextEncode.text`), 결과 이미지 출력(예: `SaveImage`)을 지정합니다.
4. 연결 확인 후 생성합니다. 입력 노드가 선택한 결과 노드까지 연결돼 있는지도 검사합니다. 참조 그림을 가져왔는데 워크플로에 참조 입력이 없으면 조용히 무시하지 않고 오류로 알려줍니다.

사용 중인 모델에 맞는 **이미지 편집/참조 워크플로**가 필요합니다. 기본 텍스트 생성 워크플로에 사진 파일 입력만 추가해도 자동으로 참조 기능이 생기지는 않습니다. 앱은 모델이나 커스텀 노드를 다운로드하지 않고 사용자의 기존 워크플로를 실행합니다. 시드·샘플러·반영 강도 등은 그 워크플로의 설정을 사용합니다.

공식 API: https://docs.comfy.org/development/comfyui-server/comms_routes

## 게임 적용과 복원

파일 메뉴의 **게임 초상화에 적용**에서 `FaceTexture` 폴더의 교체할 기존 BMP를 직접 선택합니다. 파일명을 유지한 채 현재 미리보기로 교체하며 원본을 먼저 백업합니다. **최근 게임 적용 복원**으로 가장 최근 적용을 되돌릴 수 있습니다. 백업은 프로그램 데이터 폴더에 보관됩니다.

## 설정과 백업 위치

이동식 배포본은 우선 프로그램 옆의 `StudioData`를 사용합니다. `portable.txt`가 없거나 프로그램 폴더에 쓸 수 없으면 아래 위치를 사용합니다. `.bdostudio` 자료함 백업에는 기본 그림·참조 그림·결과·폰트·편집 설정이 포함되며, 게임 파일의 원본 백업(`backups/`)은 별도로 보관됩니다.

- Windows: `%LOCALAPPDATA%/BDOPortraitStudio`
- macOS: `~/Library/Application Support/BDOPortraitStudio`
- Linux: `$XDG_DATA_HOME/bdo-portrait-studio` 또는 `~/.local/share/bdo-portrait-studio`
- 별도 위치 사용: `python run.py --data-dir /원하는/폴더`

## 개발·검증·패키징

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m pip install 'pyinstaller>=6,<7'
python build.py
```

운영체제마다 그 운영체제에서 빌드해야 합니다. Windows에서 만든 exe는 Mac/Linux 실행 파일을 대신하지 않습니다. `.github/workflows/build.yml`에는 GitHub Actions 수동 실행용 Windows/macOS/Linux 빌드 구성이 포함돼 있습니다. 이 배포에서 실제 실행·패키징을 검증한 OS는 Windows이며, Mac/Linux용 실행 파일은 해당 환경에서 빌드·검증해야 합니다.

현재 검증에서는 실제 API 키나 로컬 ComfyUI가 제공되지 않아 실제 모델 추론은 실행하지 않았습니다. v1.0에서 로컬 시험 서버로 통신을 확인했고, 이후 버전은 네트워크 없이 실행하는 HTTP 응답 대역으로 요청·응답·오류 처리를 검사합니다. 자료함은 원본 파일 삭제, 앱 재실행, 새 위치 복원, 폰트·참조·결과·편집 상태 복원을 검사합니다. v1.2 웹 경로는 요청문·첨부 원본 준비, 클립보드 복사, 브라우저 열기 호출, 드롭 경로 파싱, 원래 클래스에 결과 보관, 재실행 및 다른 위치 백업 복원을 검사합니다. 실제 ChatGPT 계정에서 생성하는 과정은 사용자가 직접 진행하며 이 검증에서 실행하지 않았습니다.

기술: Python / Tkinter / Pillow / tkinterdnd2(TkDND). 검은사막 기본 그림·참조 그림·생성 모델은 포함돼 있지 않습니다.
